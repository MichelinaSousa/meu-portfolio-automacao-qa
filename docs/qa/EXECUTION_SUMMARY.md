# Sumário de Qualidade da Execução

Este arquivo é atualizado automaticamente pela Fase 5.

## Como gerar

1. Rodar a suíte de API completa em JSON:
   - npm run test:api:all:json
2. Gerar o resumo:
   - npm run report:qa

Ou executar em um único comando:
- npm run phase5:evidence

## Saída esperada

- Total de testes
- Passed / Failed / Timed out / Skipped
- Taxa de sucesso
- Duração total
- Distribuição por projeto
- Resultado por arquivo
